# 关于SLOTS+游戏经济膨胀与现实世界关联

## 引子

在玩《Top Tycoon》（Slots+棋盘翻地游戏）的过程中，发现了一个很不一样的地方：1美金在游戏内的实际购买力是极快的。以常驻直购体力为例，第一天，10美金能买400体力。第二天买600体力，第三天则是800体力。

这个体验对我而言是比较新鲜而罕见的。不管是同为SLOTS游戏的《Coin Master》，还是其他游戏比如说二游（比如星铁、Niike），游戏货币的购买力在前期都是较为稳定的。如果是一个原p，应该会默认648元=6480原石=每1抽要花160原石。

一开始以为是这游戏数值算坏了，持续体验+记录了一段时间，发现这个体验背后其实有清晰的原因。新手期头几天，用来兑换体力的汇率被刻意设得涨得很快，让玩家一上来就感受到"钱越花越值"的强烈爽感。这就是奇妙的"通货膨胀"带来的美好感受！

![开局三天购买力反差](charts/chart4_开局购买力反差.png)

我又换了几个账号，玩了一段时间。发现虽然我10美金能买到的体力在涨，且虽然同样的体力能换到更多的金币（金币去扩张地图）但我推进地图的速度也慢了下来。之前几十美金一个地球的进度，现在过不了一个区域。

也就是说，我实际用美元买到的进度，因为游戏中数值策划的阴谋，被偷偷降低了！我想知道其中的原因。

因为货币体验是游戏、也是世界经济史中重要的一部分，通货膨胀、通货紧缩也是常见的范式。问题在于，这背后到底是什么在起作用——为什么这个游戏，非要维持这么一种微妙的"膨胀"。这种膨胀具体体现在哪几个地方。这套经济系统，又是靠什么撑住不失控的？而这种膨胀，落到不同的玩家身上，体验又为什么会完全不一样...

最终我大致有这样的结论：
开局那几天购买力在涨（400→600→800），跟后面发现的"温和膨胀"（钱越来越不经花），方向是反的。
这本质是两套完全不同的机制，只是刚好都用"钱值不值"来体现。
开局那几天购买力上升，做的是"钩子"——目的是让新玩家第一时间尝到甜头，产生"这游戏真划算"的第一印象，这个阶段越短越好，越猛越好，跟长期运营没有关系，纯粹是获客手段。
而真正决定这个游戏能不能长期健康运转的，是新手期过后那条持续、缓慢下降的购买力曲线。前面是烟花，放完就没了；后者才是这个游戏经济系统真正的发动机，要撑得住整个生命周期。
这个反差本身也说明一件事：同一个"购买力"的数字，在不同的阶段，服务的是完全不同的目的，不能拿开局那几天的观感，去套后面几十个小时的经济系统该怎么设计。

## 一、为什么要"通货膨胀"

第一反应很容易是——膨胀是不是一种失控？是不是应该想办法把它消灭掉，让玩家的钱始终保值？

这个直觉在我自己身上也出现过，直到玩到一个很有意思的小游戏《THE CENTRAL BANKER》。玩法是你扮演央行行长，管十年，每年从"加息/不变/降息"三个选项选一个，系统会实时显示CPI、GDP增速、失业率、基准利率，每做完一个决策还会告诉你两年前那次决策"滞后显效"了多少。

玩到最后，是这么结束的：连续几年一路降息，降到基准利率2%，本以为可以力挽狂澜了！结果CPI变成负数，GDP变成负数……失业率反而从4.5%的目标一路涨到9.0%。降息降到最后已经不起作用了，经济被系统标记成"通缩螺旋（Deflation）"，游戏判定这是一个失败结局。

![THE CENTRAL BANKER十年轨迹](charts/chart5_央行游戏轨迹.png)

这个小游戏的结局，恰好回答了最开始那个直觉——"零通胀"或者"通缩"，才是真正可怕的东西，不是"温和膨胀"。一旦大家都预期"东西会越来越便宜"，理性选择就是"能拖就拖，反正明天更便宜"，需求持续萎缩，企业裁员，失业率往上走，即使央行拼命降息想刺激消费，也没人愿意花钱——这就是"通缩螺旋"，钱变得越来越"值钱"，但整个系统反而在死亡。这也是为什么几乎所有央行的通胀目标不是0%，而是2%左右。一点点"温和的、可预期的"物价上涨，才能持续制造"现在花比将来划算"的紧迫感，维持系统的运转。

放回游戏里，答案就清楚了：如果体力供应涨得比消耗还快，玩家会发现"不管等多久，体力反正都够用，不用着急、更不用花钱"——这跟通缩是一模一样的死亡螺旋。所以金币消耗持续跑赢体力供应，不是bug，也不是设计失控，而是这套商业化系统能够运转起来的根本引擎——只是这个"跑赢"的幅度，要控制在"温和"这个区间里，跟央行把通胀目标钉在2%而不是20%是同一个道理。

## 二、膨胀具体体现在哪几个地方

搞清楚"为什么必须膨胀"之后，下一个问题是——这个膨胀到底是靠什么东西在具体承载的？

答案是两条曲线的叠加：一条是流水目标（策划刻意设计的难度爬升节奏，玩家推得越深、门槛涨得越快），另一条是兑换效率曲线（体力换金币、美元换体力的汇率，随着进度分档跳涨）。这两条曲线的涨幅，被设计成持续超过体力供应（每天固定能拿到多少）的涨幅，这个持续跑赢的缺口，才是整套系统的真正引擎。

![流水目标节奏曲线](charts/chart2_归一值曲线.png)

这里要提一个容易被忽略的细节（这是《Top Tycoon》的做法）——这两条曲线不是匀速上涨的，而是"分档跳涨"的，像上台阶一样。而每一次跳档，都是一个需要格外小心的节点，因为跳档的瞬间，两个数字同时往上跳的速度，可能会短暂超过难度本身变难的速度，制造出一段不在设计意图之内的、短暂的"购买力回涨"窗口——这跟前面说的"开局那几天故意做的购买力上升"完全不是一回事……

这也是为什么《THE CENTRAL BANKER》里那个"两年前政策滞后显效"的机制让我印象很深——今天看到的任何一个膨胀数字，往往不是当下一拍脑袋决定的，而是好几层此前的设计选择，叠加延后显现的结果。游戏里的DTE分档、ETC分档、难度曲线跳档，都是提前很久埋下的设计，真正的效果要等玩家实际推进到那个节点才会显现——这意味着，任何一次"发现膨胀跑偏了"，往往已经是好几个版本之前的选择在起作用，想要修正，也得往前倒查，而不是只盯着眼前这一区改。

## 三、这套系统，靠什么撑住不失控

### 3.1 费雪方程

如果只是"让两条曲线持续跑赢供应"，很容易滑向失控——那怎么知道跑赢的幅度是不是"温和"，而不是正在滑向恶性通胀？这里要借用一条最基础的经济学公式——费雪方程式。最初用于解释经济世界的通货膨胀：

```
货币供应量（M） × 货币流速（V） = 价格水平（P） × 真实产出（Q）
```

和Slots传统机台对比，做一个转换：

```
M（体力供应）× V（流通速度）= P（金币消耗物价）× Q（真实内容产出）
```

这里的流通速度，恰好和机台返比有关。也就是 **V = 1 ÷ (1 - RTP)**。

![RTP与流通速度乘数](charts/chart6_RTP乘数曲线.png)

这条公式说的是：如果货币供应涨得比产出快，货币的流通速度不变（体现在游戏中则是机台RTP维持基本恒定），物价就必须跟着涨（游戏内体现为岛屿消耗金币量），账才能对上。

这条公式也顺带回答了一个问题——真正决定购买力的，到底是哪个数字？用一步代数就能看清楚。设汇率为R，兑换效率为E，难度门槛为D，那么：

```
金币消耗 = D × E
真实购买力 = (R × E) ÷ 金币消耗 = (R × E) ÷ (D × E) = R ÷ D
```

E直接约掉了。真实购买力只取决于汇率和难度门槛，跟兑换效率这个中间变量完全无关——这也是为什么兑换效率这条曲线可以设计得很陡峭，专门用来制造视觉爽感，不用担心拖累玩家的真实体验。嘻嘻。

### 3.2

那这套系统什么时候该"踩刹车"？答案不是看单独一次异常，而是看持续的趋势。这正好呼应《THE CENTRAL BANKER》里那个容易被忽略的评分机制——连续几年政策方向一致，给"政策连贯+20%"的加成；如果来回摇摆，直接"政策摆摆-40%"扣分。这跟真实世界里央行反复强调的"不要因为单月数据波动就慌乱调整政策"是同一个道理：一次孤立的、跳档处的购买力回涨，更像是噪音，回去修那个具体节点就够了；真正该动用"系统性收紧"的时机，是连续多个版本，物价涨幅持续、稳定地跑赢供应涨幅，还没有自己收敛的迹象。

![大R真实购买力走势](charts/chart1_ppp曲线.png)

而"收紧"这个动作本身，也不是只有一种力度。游戏里遇到"次贷危机"这种随机重大冲击时，给了三个选项——紧急救市（降息100bp，代价是"流动性陷阱"风险）、强力宽松（75bp）、常规操作（50bp，但"力度可能不足"）——每一档都明说了代价，不是无脑选最大力度就是对的。这对应到我们的游戏设计里，就是"全面放水"（调整全局的免费发放）和"精准滴灌"（只针对某个区域、某个人群单独加成）这两种手段的选择——前者影响范围大、风险也大，后者精准，但只能解决局部问题，两者该怎么选，取决于问题本身是局部的还是系统性的。

回到SLOTS游戏，我们也有不同的方式应对：

**(1) 紧急救市**——直接压低几个区域的"归一值"节奏曲线，把这几关的流水目标门槛整体往下拉。这是最猛的一档，见效最快，但代价也最大——因为归一法是把大R预算锚定到整条曲线上的（这是我们在做《PT》的思路，但也有其他方式），直接压低某几区的门槛，这意味着要么大R的整体付费深度被稀释，要么后面几区得反过来补涨来找平，牵一发动全身，跟游戏里"紧急救市"要面对的"流动性陷阱"风险是一个意思。

**(2) 提升免费玩家的发放**——只调"每日免费恢复量"这一个参数，覆盖所有卡壳的区域。这一档比第一档温和，只影响免费部分，不碰大R的费用结构，但因为"每日免费恢复"是免费玩家和中R共用的同一个参数，调猛了会连带把中R的"付费划算感"也稀释掉——这跟游戏里"强力宽松"是同一个位置：影响范围比紧急救市小。

**(3) 精准滴灌**——只在具体卡壳的那几个区域，给特定人群单独加成（比如我们会在中R在12-14区加30%，因为它们在这个地方的过岛天数太长），不碰其他任何参数。这一档最保守，代价也最直接——它只能解决局部问题，如果问题其实是系统性的（比如好几个版本都在同步恶化），这种精准手段只是在"打地鼠"，一个区域治好了，下一个区域可能又冒出来，治标不治本，就像游戏里"常规操作"那句提示写的——"力度可能不足"。

三档怎么选，最终还是回到前面——取决于问题本身是局部的，还是系统性的。

## 四、同样的膨胀，落在不同玩家身上，体验为什么完全不一样

最后一个问题——同一条"温和膨胀"的曲线，为什么大R、中R、免费玩家的感受完全不同？

因为他们走的不是同一条"资金通道"。大R一次性投入一大笔预算，他们的钱是存量资本，直接砸进去就能跳过大部分等待时间。中R每天花一笔固定小钱，类似工薪族。免费玩家完全不花钱，只靠每天固定的体力恢复，像"完全不参与资本市场、只靠纯劳动时间换取资源"的人。经济学家皮凯蒂提出的r>g（资本回报率长期跑赢经济整体增长率）说的正是大R和免费玩家之间的这种差距——靠存量资本获益的速度，天然比靠时间堆出来的速度快。

![三人群体验对比](charts/chart3_三人群对比.png)

这个拆分带来一个很实际的教训——我自己一开始有个直觉，觉得既然大R有汇率、兑换效率可以调，那免费玩家的体验应该也能靠类似的杠杆去提速吧？后来实际去反推公式才发现，免费玩家的进度只取决于两个东西：难度门槛本身，和每天固定能拿到多少体力，跟金钱、汇率、兑换效率完全没关系。

这跟"央行调整存款利率，不会影响一个完全不用银行、只靠现金收入攒钱的人"是同一个道理——三类玩家走的是三条完全不同的资金通道，用错误的杠杆去调某一类人的体验，力气基本是白费的。

也正因为如此，"温和膨胀"这条曲线，对大R而言只是"钱越来越不经花，但反正一次性投入的多，感受不明显"；对中R而言是"每天固定投入，随着曲线走高，需要投入的天数会持续拉长，能明显感受到节奏在收紧"；对免费玩家而言，膨胀这件事本身跟他们几乎无关，他们真正在意的只有"门槛涨得快不快、每天恢复够不够"——同一条曲线，映在三面完全不同的镜子上，长成了三种完全不同的体验。

## 写到最后

回头看，游戏里那个几块钱的小波动，跟历史上真实吞掉过无数人积蓄的大崩溃，规模差了不知道多少个数量级；一个真实的央行决策，跟一个十分钟就能玩通关的小游戏，严肃程度也天差地别。但这几件事背后运作的逻辑，好像真的是同一套东西——钱能不能循环、涨得快不快、不同人手里的钱是不是同一种钱、以及这一切该靠单点判断还是靠持续趋势去校准，这几个问题，在哪个尺度上都绕不开。

我不确定自己现在的理解是不是完全正确，但至少目前拿这套框架去回看那些游戏里原本看起来随意的数字，很多曲线突然就有了能讲清楚的道理。
