# 问 PT开发小助手（飞书）提问模板

服务端代码不在本地，规则以开发小助手答复为准。一次问清，答复写回对应 references。

## 通用模板

```
【需求】<一句话需求，例：首日给新玩家推一个三段式礼包>
【涉及表】<pango 上看到的表名 + 主键>
【想确认】
1. 触发：服务端按什么判定可见？（注册时长 / 生命日 / 积分阶段 / 付费状态 / 等级）
   生命日按注册后 24h 还是自然日？哪个时区？
2. 解锁与顺序：第 N 段是否必须买完 N-1 段？是否允许跳段？
3. 限购与过期：每段限购次数；整组倒计时多长；过期后是否还能再出现？
4. 发奖：奖励发放走哪个接口？是否受新手期剧本 / 积分卡点水池影响？
5. 冲突：与 <三日新手礼 / 爬塔礼包 / 一段式礼包> 同时满足时，弹窗优先级与互斥规则？
6. 埋点：t_pay_flow 的 scene_id 填什么？是否有 packagekey 区分同价不同内容？
7. 配置生效：改表后是否需要发版 / 重启？测试服→体验服→预发布服的同步方式？
```
