## 已确认结论（可直接引用）

- 付费留存双端无差异；次日加权约 66%；**没有下降趋势**（曾被未满期数据误导）
- 衰减断点在第 3→4 天；之后走平
- **首笔→次笔转化 52.1%** 是全链路最低点，之后各档 60–93%
- 收入高度集中：买 ≥5 笔的人贡献约一半收入；前 4 笔累计约 73%
- 收入约 **72% 集中在首日**
- 卡点在阶段 4（到达率 58.6%→15.4%）；付费几乎全在阶段 5 之后
- 内容终点约阶段 43；大 R 靠多笔小额堆到 $50+，单笔通常 ≤$25
- 双端留存无差异；安卓几乎没有大 R，档内人均一致
